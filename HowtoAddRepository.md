# How to Add a Repository

## Summary

How to clone my remote GitHub repository locally using Visual Studio Code.

## Prerequisites

You have to be logged in to your GitHub account and have at least one repository created there, which is not already cloned to your PC.

## Steps

1. Navigate to the repository's dashboard.
2. Click on the "Code" button and select HTTPS.
3. Copy the repository url.
4. In VS Code add a new folder
